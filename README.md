# QuickMark 0.7.13

一个为高刷新率显示器、快速框选、标注和复制制作的原生 macOS 菜单栏工具。

## 启动

从源码仓库下载后，先在项目目录运行 `./build.sh` 生成应用，再按下面的方式启动。

双击同目录下的 **QuickMark.app**。当前构建适用于 Apple Silicon（M 系列）和 macOS 14 及以上版本。

应用常驻右上角菜单栏，不占用 Dock。可以把整个应用拖到「应用程序」文件夹后再打开；移动位置或重新编译后，系统可能要求重新授予屏幕录制权限。

首次截图时按系统提示授予「屏幕与系统音频录制」权限。程序仅截取屏幕图像，不录制音频。若系统要求重新启动，请退出后重新打开。欢迎页的「先试试标注」无需录屏权限。

## 最短操作路径

1. 按 **⌘⇧4**，鼠标下的前台窗口会高亮；桌面空白处高亮当前整块屏幕。**直接双击高亮窗口即可复制**，无需先单击选中；也可单击选取后标注，或直接按下拖动自由框选。
2. 选区使用蓝色细边线和四角折角，不显示控制点。拖动四角／四边中点调整范围，拖住其余边线移动选区；悬停时会显示对应方向的系统缩放光标或抓手。在选区内标注，默认工具为方框（R）。画出的矩形保留八个控制点，也支持缩放和边线移动。
3. **双击选区**、按 **Enter** 或 **⌘C** 复制；回到目标应用按 **⌘V** 粘贴。按 **T** 可将选区连同标注固定在屏幕上。

中键保存：框选并标注后，在选区内点击鼠标滚轮（中键），自动将原分辨率 PNG 保存到桌面并退出截图；固定贴图上的中键保存会保留贴图。文件名包含时间，同名时自动增加编号，不覆盖已有文件。保存失败会保留选区供重试。

文字工具：按 ⌘T 后点击选区输入文字，按 Enter 确认；再次按 Enter 复制截图。文字输入期间，⌘C/⌘V 保持普通文本编辑行为，Esc 取消本次文字输入。

固定截图：T 将当前选区和标注按原位置、原大小直接固定为置顶小窗，没有缩放或淡入过渡，结束截图后返回工作。拖动图片移动；鼠标滚轮、触控板双指上下滚动可放大缩小；单击贴图后，两指沿对角线张开／捏合也可放大缩小，缩放围绕鼠标所在的图像位置进行，停手后不继续惯性缩放。双击或 ⌘C 复制原分辨率图像，显示缩放不影响剪贴板清晰度。贴图没有关闭图标；右键单击贴图立即关闭，也可点击使其获得焦点后按 Esc 关闭。支持同时固定多张图片；固定操作本身不会改写剪贴板。

工具条提供六种颜色、三档线宽和重新框选。每次框选可在一个显示器内完成；其他显示器会在选定后恢复显示。若快捷键被其他应用占用，可通过菜单栏启动截图。

截图按快捷键时的可见画面取样，包括已有贴图及其阴影。截图前不隐藏或重新排列窗口；框选面板不激活 QuickMark，结束后只撤下截图层，保留原来的前台应用。若截图前选中了 QuickMark 的贴图，结束后恢复该贴图的选中状态。

## 本版改动

- 0.7.13：修正截图时贴图短暂消失和焦点来回切换的问题。删除截图前隐藏贴图、截图后重新显示的处理，保留屏幕原样；框选使用不激活应用的面板，取消或结束后不再主动切换到其他应用。各屏幕的截图底图、首次悬停高亮和辅助线先准备完成再显示，收起截图层时保留其内容直到窗口退出显示，避免空白中间帧。
- 0.7.12：菜单栏展开的菜单新增当前版本号与发布时间，两行灰色说明位于退出操作上方。版本从当前运行应用的版本信息读取，发布时间在构建打包时记录，按北京时间显示到分钟，重启不会改变。
- 0.7.11：选中的固定贴图四周显示简洁的淡蓝色柔和阴影，点击另一张贴图时随焦点切换。阴影位于图像外侧，不拦截鼠标操作；移动、缩放时同步跟随，复制和保存仍使用原分辨率图像。
- 0.7.10：反转固定贴图的鼠标滚轮放大／缩小方向，普通滚轮与无手势阶段的高精度／平滑鼠标滚轮均生效。保留系统自然滚动设置的方向归一化、原有细调幅度和 1.5% 上限；触控板双指滚动与捏合方向保持原样。
- 0.7.9：窗口或桌面整屏高亮后可直接双击复制，第一次选取点击计入双击，无需先单击选中。第二下点击优先于选区边缘编辑及刚弹出的工具条处理；拖动框选不计入复制双击，单击选取后标注保持可用。
- 0.7.8：截图前不再隐藏主窗口，主窗口保持原样并包含在截图中，避免截到系统隐藏窗口时的半透明虚化过渡；旧系统截图路径保持相同表现。主窗口和提示窗禁用系统显示／隐藏动画，截图请求进行中不响应重新打开主窗口的事件。保留 ⌘W 主动关闭和窗口阴影。
- 0.7.7：支持 ⌘W 关闭主窗口，菜单栏和全局截图快捷键继续运行。修正截图后应用窗口阴影消失：macOS 26 及以上的区域截图接口默认忽略阴影，现显式保留系统窗口阴影和遮挡关系；旧系统兼容路径也显式保留阴影。
- 0.7.6：截图四角折角的短边由 12 点加长至 18 点，线宽保持 3 点；角点缩放命中范围覆盖加长后的折角。很小的选区仍自动缩短折角，边线移动及四边中点缩放保持原有行为。
- 0.7.5：修正长十字辅助线的蓝色发暗：移除两侧残留的半透明黑边，使用纯 #2BABFF 的 1 点细线（Retina 为 2 物理像素），按物理像素对齐。截图边线按当前像素密度渲染；矩形光标同色行为保持不变。
- 0.7.4：直接取样参考截图的十字线颜色，截图十字、辅助线和外框统一为 #2BABFF（RGB 43、171、255）；保留细线及矩形绘制光标跟随标注颜色的行为。
- 0.7.3：截图十字和辅助线使用 macOS 标准系统蓝色，保留 1 点细十字；矩形绘制光标继续跟随标注颜色。
- 0.7.2：截图十字改为更淡的蓝色，去除原来的粗白描边，彩色十字线宽由整体 3 点收细到 1 点；辅助线也使用浅蓝色。矩形绘制光标跟随工具条中当前的标注颜色，默认红色，悬停和按住拖动画框时保持一致。黑白标注光标保留轻微对比边以便辨认。

- macOS 15 及以上使用系统对应方向的框架缩放光标，包括四角的斜向双箭头；边线移动使用系统张手／抓手。macOS 14 保留系统横向、纵向缩放光标，角点使用系统十字兼容。
- 截图十字光标及长辅助线统一为蓝色。小型十字通过静态 NSCursor 交给系统移动，光标和逐屏显示刷新路径保持独立。
- 0.7.0：截图选区和矩形标注均支持四角、四边中点共八个缩放手柄；拖住其余边线可移动整个框。刚画好的或鼠标悬停的矩形显示手柄，矩形内部仍可继续画新标注。
- 选区外框优先命中；矩形标注按绘制顺序从上到下命中。移动选区改变截取范围，标注留在对应的截图内容位置；选区缩放不会拉伸底图或已有标注。
- 每次拖动只记录一步撤销／重做；选区不能拖出屏幕或缩小到 8×8 点以下。控制点不会出现在复制、保存或固定后的图片里。
- 编辑沿用按显示器刷新率更新的矢量图层，矩形调整复用已有图层，不重新上传截图或重绘其他文字。
- 0.6.3 新增右键单击关闭固定贴图，不需要先用左键激活；保留 Esc 关闭。
- 全局截图快捷键、菜单栏和欢迎页统一改为 ⌘⇧4。
- 0.6.2 修正连续双指上下滑动时缩放停住：移除会把两指间距轻微变化误判为捏合的触点识别，使用 macOS 原生捏合事件；滚动不再被捏合状态锁住。保留双指张开／捏拢和上下滚动两种缩放方式。
- 再次调细鼠标滚轮：常见三行事件约放大 0.6%，单次最多放大 1.5%，反向使用倒数比例。无手势阶段的高精度／平滑鼠标滚动也走细调路径，避免被当作触控板；带系统手势阶段的触控板上下滑动与原生捏合保留原灵敏度。
- 保留 0.6.1 的焦点修复：单击贴图会激活 QuickMark，从而接收系统捏合事件；显示贴图和悬停保持不抢焦点。
- 鼠标中键直接将当前选区或固定贴图保存为桌面 PNG。
- 截图启动移除固定 180ms 等待。macOS 26 及以上使用直接区域截图接口，绕过每次查询完整可共享内容列表；多显示器并行截图。旧系统保留兼容路径。此前双屏诊断测得首次约 508ms、再次约 272ms 到覆盖层提交；这是两次测试样本，不是物理按键到显示延迟，也不代表所有负载下的表现。
- 文字标注去掉模糊阴影，按物理像素对齐；固定后放大时重新渲染文字，复制仍使用原截图分辨率。
- 默认方框标注、小型纯十字光标、无关闭图标，直接固定且没有过渡动画。

## 高刷新率实现与验证

- 小型蓝色纯十字通过静态 NSCursor 图像交给 macOS 光标系统独立移动；没有隐藏系统光标后用软件定时器模拟光标。调整大小直接使用系统方向光标。
- 长十字辅助线、窗口高亮、选区和标注使用 Core Animation 独立图层；截图底图只上传一次。
- 每个显示器使用自己的 CADisplayLink，申请该屏幕最大刷新率；在每次回调中读取最新鼠标位置。不会把 160Hz 外接屏与 60Hz 内置屏统一锁到 60Hz。
- 开始截图时缓存按前后顺序排列的窗口列表；移动时只在内存中命中窗口，不反复截图或查询 WindowServer。高亮对应截图时的窗口位置，按矩形边界判断。
- 贴图拖动使用独立的 CADisplayLink，在每次显示回调中采样最新鼠标位置并更新窗口位置；跨屏时申请目标显示器的最大刷新率。底图只上传一次；箭头、方框和画笔使用矢量图层，文字按放大倍率重新栅格化，缩小时复用高清字形；空闲时停止显示回调，不使用系统模态拖动循环或平滑插值动画。
- **F** 面板显示的是屏幕刷新率、显示回调速率、回调间隔 p95 和图层更新 CPU 耗时 p95，不能把回调次数当作物理面板实际呈现帧数。

在此电脑的 P27H2V（当前模式 160Hz，渲染尺寸 4608×2592）上进行 8 秒合成移动测试，跳过前 0.5 秒预热。0.3 构建测得回调约 160.0/s，回调间隔 p95 为 6.40ms，图层更新 CPU p95 为 0.12ms；1237 个样本中没有回调间隔超过 1.5 个目标帧周期（9.375ms）。内置屏独立约 60.0/s。数据见 `performance-report.json`。

这验证了应用的更新节奏和 CPU 预算；不代表已经测得物理光标运动到屏幕发光的端到端延迟，也不保证所有系统负载下都无掉帧。光标手感仍需在实际显示器上体验。

可重复运行基准测试，显示的都是生成画布，不读取真实桌面：

```sh
./QuickMark.app/Contents/MacOS/QuickMark --benchmark --report performance-report.json
```

测试时会暂时覆盖两块屏幕约 8 秒，Esc 可提前退出。

贴图移动基准使用真实的窗口位置更新路径和生成图片。0.5 当前测试环境为 U2790B 60Hz 外屏和 60Hz 内置屏，回调约 59.5/s，窗口位置更新 CPU p95 分别约 0.55ms / 0.79ms，报告见 `pinned-performance-report.json`；之前 0.4 在 P27H2V 160Hz 上的记录保存在 `pinned-performance-report-0.4-160hz.json`，不代表 0.5 已重新验证 160Hz。运行方式：

```sh
./QuickMark.app/Contents/MacOS/QuickMark --benchmark-pins --report pinned-performance-report.json
```

基准分别在每个显示器移动一张生成贴图约 8 秒，记录回调、窗口位置更新次数和 CPU 耗时；不读取桌面，也不测量物理呈现帧率。

## 数据与当前范围

- 图像在内存和本机处理，没有联网、上传或后台录屏。
- 只有主动复制时写入剪贴板、主动保存时写入文件。
- 导出按截图源的物理像素尺寸生成，保留 Retina 清晰度。
- 本版支持窗口 / 桌面整屏高亮与单击选取、区域截图、基础标注和置顶贴图；暂不支持跨屏选区、箭头／画笔／文字标注的移动编辑、OCR、长截图和历史记录。部分被遮挡窗口选择后仍保留截图中的遮挡内容。
- 这是本地开发构建，采用临时签名，尚未做开发者 ID 签名或 Apple 公证。

## 修改和构建

安装 Xcode 或对应命令行工具后，在本目录运行：

```sh
./build.sh
```

无需第三方依赖。源码在 `Source/`：

- `PNGExport.swift`：桌面 PNG 写入、时间命名与防覆盖。
- `App.swift`：菜单栏、全局快捷键、截图流程、欢迎页、保存与剪贴板。
- `ScreenCaptureService.swift`：按需并行截图、原生区域截图和旧系统兼容路径。
- `Overlay.swift`：框选层、工具条、矩形编辑、撤销重做、鼠标与键盘交互。
- `RectangleEditing.swift`：共用的八点手柄、边线命中和矩形缩放／移动几何计算。
- `HighRefresh.swift`：窗口命中、十字光标、分层渲染与显示回调统计。
- `Drawing.swift`：标注绘制、按原始分辨率裁剪导出、练习画布。
- `PinnedCapture.swift`：无动画置顶截图、按显示器刷新率拖动、滚轮 / 捏合缩放、复制和关闭。
- `GestureDiagnostics.swift`：显式开启的生成贴图手势诊断，仅记录事件类型、状态和缩放数值。
- `SelfTest.swift`：图像渲染和交互回归测试。
- `PerformanceTest.swift`：通过生产渲染路径执行的多显示器合成移动基准测试。

运行图像测试：

```sh
./QuickMark.app/Contents/MacOS/QuickMark --self-test
```
